# 04 — Прошивка ESP32 и контракт с Jetson

ESP32 — это слой реального времени и безопасности. Главное правило:
**ESP32 должен уметь остановить робота сам, без Jetson и без карты.**

> 📦 **Код прошивки готов:** `firmware/esp32_base/` (PlatformIO, micro-ROS, Serial).
> Сборка/прошивка и проверка — в `firmware/esp32_base/README.md`.
> Пины и параметры — в `firmware/esp32_base/include/config.h`.
> Текущая разводка: 1× L298N, борт = канал (левые моторы → A, правые → B).

## Контракт с Jetson (интерфейс, который не меняется)

**Вход (ESP32 подписывается):**
- `/cmd_vel` — `geometry_msgs/Twist`: `linear.x` (вперёд, м/с), `angular.z` (поворот, рад/с).

**Выход (ESP32 публикует):**
- `/imu` — `sensor_msgs/Imu` (с BNO055).
- (когда появятся энкодеры) `/wheel_ticks` или сразу `/odom`.
- (опц.) `/rover/status` — состояние слоя безопасности (стоп/ок, причина).

Пока контракт соблюдён — верхний и нижний слои независимы и тестируются отдельно.

## cmd_vel → колёса (skid-steer)

Перевод желаемых скоростей в скорости бортов:
```
v_left  = linear.x - angular.z * (L/2)
v_right = linear.x + angular.z * (L/2)
```
`L` — колея (расстояние между бортами). Дальше скорость борта → ШИМ.

> Без энкодеров это **open-loop**: ШИМ ≠ реальная скорость. Калибруется грубо
> (подбором коэффициента и мёртвой зоны ШИМ). «Прямо» будет приблизительным —
> это ожидаемо до установки энкодеров и замыкания контура.

## Слой безопасности (обязателен)

1. **Watchdog по cmd_vel.** Каждое сообщение обновляет таймер. Нет команды > `CMD_TIMEOUT_MS`
   (старт 300 мс) → ШИМ = 0. Это ловит зависший Jetson, обрыв USB, упавшую ноду.
2. **Аварийный стоп (когда будет кнопка/бампер).** Прерывание на GPIO → немедленный стоп,
   игнор cmd_vel до сброса.
3. **Лимит по току/времени.** Защита от заклинивания мотора.
4. **Плавный пуск** (рамп ШИМ) — щадит L298N и питание, меньше просадок.

## Что тестируется на ESP32 отдельно (без Jetson)

- Реакция ШИМ на ручные команды (сериал-монитор / тестовый скетч).
- Watchdog: подать команду, перестать — колёса должны встать через таймаут.
- Мёртвая зона ШИМ: минимальный сигнал, при котором мотор реально крутится.
- Чтение IMU: адекватные углы при наклоне.

## Заглушка зарядки (для теста режима charging)

Зарядной станции нет. На этапе тестов поведения:
- `/rover/status` может отдавать поле `battery` как изменяемую вручную переменную,
  либо состояние «docked/charging» выставляется по приходу робота в «виртуальный док»
  (заданную позу). Так проверяется логика цикла заряда без реального контакта.
