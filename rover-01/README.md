# rover-01

Паспорт первого прототипа мобильного робота проекта GreenHouse.
Папка растёт по мере сборки: здесь архитектура, железо, драйвера, прошивка и план тестирования.

## Что это за робот

Автономная 4-колёсная платформа на ROS2. Мозг — NVIDIA Jetson Orin Nano,
низкоуровневое управление моторами — ESP32 + драйвер L298N, основной сенсор — RPLIDAR.
Цель прототипа: проверить навигацию, объезд препятствий, переключение режимов
и аварийную остановку в ограниченной тест-зоне.

## Ключевые решения и ограничения (читать перед сборкой)

- **Привод:** skid-steer (поворот за счёт разной скорости бортов), 4 простых DC-мотора.
- **Энкодеров пока НЕТ.** Это главное ограничение: нет честной одометрии с колёс.
  На старте одометрия берётся из лидара + IMU. Энкодеры заложены в план как
  обязательный апгрейд перед серьёзными тестами навигации (см. `docs/02-hardware-bom.md`).
- **L298N — open-loop.** Обороты зависят от заряда батареи; «прямо» будет приблизительным,
  пока не появится замкнутый контур по скорости (нужны энкодеры).
- **Нет зарядной станции и физической нулевой точки.** Origin карты = поза при старте.
  Зарядка на этапе тестов — программная заглушка.

## Три слоя (основа архитектуры)

1. **Слой безопасности** — на ESP32: watchdog, лимит тока, аварийный стоп. Не зависит от карты и от Jetson.
2. **Слой навигации** — Jetson: лидар, SLAM, Nav2, запретные зоны.
3. **Слой поведения** — Jetson: машина состояний и режимы.

Тестируются снизу вверх. Подробности — в `docs/01-architecture.md`.

## Статус сборки

| Компонент            | Статус        | Примечание                                  |
|----------------------|---------------|---------------------------------------------|
| Jetson Orin Nano     | 🟡 заказан    | Поставить Ubuntu + ROS2                      |
| RPLIDAR              | 🟡 заказан    | Драйвер sllidar_ros2                         |
| Шасси 4WD + L298N    | 🟢 есть       | Подключить к ESP32                           |
| ESP32                | 🟢 есть       | Прошивка готова: `firmware/esp32_base/` (micro-ROS) |
| Энкодеры             | 🔴 нет        | Апгрейд перед тестами навигации             |
| IMU (BNO055)         | 🔴 нет        | Желателен для одометрии                      |
| Аварийная кнопка/бампер | 🔴 нет     | Нужен для слоя безопасности                  |
