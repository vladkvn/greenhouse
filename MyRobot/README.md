# MyRobot — проект Webots для macOS

Готовый колёсный робот с **лидаром, камерой и датчиками расстояния** в комнате с препятствиями. Робот ездит и сам объезжает препятствия.

## Как запустить (3 шага)

1. **Установи Webots** (если ещё нет):
   ```bash
   brew install --cask webots
   ```
   или скачай `.dmg`: https://github.com/cyberbotics/webots/releases

2. **Открой мир:** запусти Webots → `File → Open World…` → выбери
   `MyRobot/worlds/my_robot.wbt`

3. **Нажми ▶️ (Play)** сверху. Робот поедет и начнёт объезжать препятствия.

## Что внутри

```
MyRobot/
├── worlds/
│   └── my_robot.wbt          # сцена: комната, препятствия, робот
└── controllers/
    ├── slam_mapper/          # АКТИВНЫЙ: ездит + строит карту по лидару
    │   └── slam_mapper.py
    └── obstacle_avoider/     # простой вариант: только объезд препятствий
        └── obstacle_avoider.py
```

**Робот:** дифференциальный привод (4 мотор-колеса), корпус-коробка.
**Сенсоры:** 2 передних датчика расстояния (объезд), 360° лидар, камера 128×64, энкодеры колёс, GPS + IMU (для маппинга), Display (экран карты).
**Комната:** пол 4×4 м, 4 стены, 3 препятствия (куб, цилиндр, коробка).

## Построение карты (SLAM-маппинг)

Сейчас активен контроллер **`slam_mapper`** — робот ездит, объезжает препятствия и **строит карту занятости комнаты по лидару в реальном времени**.

- **Где смотреть карту:** в Webots появится небольшой экран (Display). Если не виден — правый клик по роботу → `Show Display Overlay`. Чёрное = стены/препятствия, белое = свободно, серое = ещё не изучено, красная точка = робот.
- **Файл карты:** каждые ~3 секунды карта сохраняется в `controllers/slam_mapper/map.pgm` (открывается любым просмотрщиком изображений).
- Это **mapping with known poses**: поза робота берётся из GPS+IMU (в симуляции — точная). Полноценный SLAM, где поза оценивается по самим сканам лидара, делается через ROS 2 + Cartographer/SLAM Toolbox.
- Если карта получится зеркальной/повёрнутой — в начале `slam_mapper.py` поправь `ANGLE_STEP`/`ANGLE_START` (одна строка, подсказка в комментарии).

Чтобы вернуть простой режим без карты — выбери робота в дереве сцены, поле `controller` → `obstacle_avoider`.

## Полезные фишки в Webots

- **Картинка с камеры / облако лидара:** правый клик по роботу → отметь `Show Camera/Lidar Overlay`, либо разверни узлы в дереве слева.
- **Графики датчиков:** двойной клик по роботу открывает Robot Window.
- **Изменить компоненты:** в дереве сцены слева можно менять параметры лидара (`horizontalResolution`, `maxRange`), камеры (`width`/`height`), позиции датчиков — и сразу тестировать.
- **Замедлить/ускорить время:** кнопки скорости сверху.
