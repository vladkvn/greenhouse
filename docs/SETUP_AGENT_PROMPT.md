# Промпт для агента: настройка локального окружения GreenHouse

Скопируй текст ниже (между линиями) и передай агенту, у которого есть доступ к терминалу
на твоём компьютере.

---

Ты — агент по настройке окружения. Твоя задача — подготовить локальную машину так, чтобы
в проекте **GreenHouse** можно было установить зависимости, запустить тесты, линтер,
проверку типов и сам код симуляции. Работай аккуратно, проверяй каждый шаг по факту
(не «должно работать», а реально выполненная команда с нулевым кодом возврата).

## Контекст проекта

- Расположение: `/Users/mac/Documents/GreenHouse` (корень репозитория).
- Python-пакет с layout `src/`: исходники в `src/greenhouse/`, тесты в `tests/`.
- Сборка описана в `pyproject.toml` (backend — hatchling).
- Требования: **Python >= 3.11**. Зависимости: `pydantic>=2.6`; dev-инструменты:
  `ruff`, `mypy`, `pytest`.
- ОС: macOS.

## Что нужно сделать

1. **Сориентируйся.** Перейди в `/Users/mac/Documents/GreenHouse`, выведи содержимое
   и `cat pyproject.toml`. Опирайся на реальный файл, а не на этот промпт, если есть расхождения.

2. **Проверь Python.** Выполни `python3 --version`. Нужна версия **>= 3.11**.
   - Если Python отсутствует или версия ниже 3.11 — установи современный Python.
     Предпочтительно через Homebrew: проверь `brew --version`; если Homebrew нет,
     установи его с https://brew.sh, затем `brew install python@3.12`.
   - Не трогай и не ломай системный Python macOS; работай через Homebrew-Python или pyenv.

3. **Проверь pip.** `python3 -m pip --version`. Если pip недоступен —
   `python3 -m ensurepip --upgrade`. Не используй `sudo pip` и не ставь пакеты глобально.

4. **Создай изолированное окружение** в корне проекта:
   ```
   cd /Users/mac/Documents/GreenHouse
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   ```
   (Если в проекте используется `uv` — `uv` тоже допустим и быстрее: `uv venv` +
   `uv pip install -e ".[dev]"`. Сначала проверь, установлен ли `uv`; если нет — venv+pip достаточно.)

5. **Установи проект с dev-зависимостями** в editable-режиме:
   ```
   pip install -e ".[dev]"
   ```
   Если установка падает на сборке — покажи полный вывод ошибки и разберись
   (типичные причины: старый pip, отсутствие интернета, несовместимая версия Python).

6. **Проверь, что всё работает** — выполни и добейся успешного результата каждой команды:
   ```
   python -c "import greenhouse; print('version', greenhouse.__version__)"
   python -c "from greenhouse.adapters.sim import build_sim_robot, greenhouse_rows_world, run; \
     r = build_sim_robot(world=greenhouse_rows_world(), start_x_m=0.5, start_y_m=1.0); \
     s = run(r, ticks=20); print('ticks:', len(s), 'mode:', s[-1].mode, 'battery:', round(s[-1].battery_frac,4))"
   pytest -q
   ruff check src tests
   mypy
   ```

## Критерий готовности (всё должно выполниться без ошибок)

- `python3 --version` показывает 3.11+ и `.venv` активируется.
- `pip install -e ".[dev]"` завершился успешно.
- `import greenhouse` работает; демо-прогон симуляции печатает `ticks: 20`.
- `pytest -q` — все тесты зелёные (ожидается 12 проходящих).
- `ruff check` и `mypy` проходят без ошибок.
