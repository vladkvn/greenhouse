# Roadmap инкрементов

Разработка идёт **вертикальными срезами**: один инкремент — рабочий, проверяемый кусок,
а не «весь слой сразу». Каждый инкремент опирается на интерфейсы из `src/greenhouse/`
и не ломает предыдущие.

Текущее состояние: **готовы Инкременты 0–11.** Зафиксированы контракты, поднят скелет
симуляции с циклом управления, реализованы построение карты (evidence-сетка по лидару),
планирование пути (A* по сетке + следование к цели), объезд препятствий, которых нет на
карте (наблюдение лидаром + перепланирование), локализация scan-matching по карте,
следование за движущейся целью, закрытые зоны (keep-out / slow / preferred), координация
нескольких роботов (резервирование сегментов проездов), автономная зарядка, автономное
исследование (frontier-based) и непрерывная актуализация карты (гейт по уверенности,
слой динамики, сохранение/слияние).

Ближайший запланированный (Инкремент 12): **слияние IMU в локализацию** — устойчивость
курса к проскальзыванию колёс.

| # | Инкремент | Что появляется | Критерий готовности |
|---|---|---|---|
| 0 | **Архитектура и интерфейсы** ✅ | `domain`, `sensing`, `control`, `navigation`, `coordination`, `orchestration`, `runtime` (Protocol + Pydantic) | Пакет ставится, импортируется, проходит type-check |
| 1 | **Скелет симуляции + цикл** ✅ | `adapters/sim`: мир-полигон + рейкаст, `SimLidar`, `SimMotion`, `SimEngine`, `SimClock`, `SimOdometry`, `SimTruthLocalizer`, цикл управления `SimRobot` | Робот стоит в симуляции, телеметрия идёт, 12 тестов зелёные |
| 2 | **Построение карты** ✅ | `EvidenceGridMapper` (лог-odds сетка по лидар-рейкасту, растеризация Брезенхэмом), хелпер `grid_meta_for_world`, режим `MAPPING` в цикле | Проезд по миру строит корректную `OccupancyGrid` (стены заняты, проход свободен, невидимое — unknown) |
| 3 | **Планирование пути** ✅ | `AStarPlanner` (A* по сетке с инфляцией под радиус робота), `PurePursuitLocalPlanner` (следование к цели), `SimGoalNavigator` + режим `NAVIGATING` | Робот доезжает из A в B по построенной карте |
| 4 | **Объезд препятствий** ✅ | `ReactiveLocalPlanner` (реактивный слой по скану) + слияние наблюдаемых препятствий в рабочую карту и перепланирование A* в `SimGoalNavigator` | Робот объезжает препятствие, которого нет на карте |
| 5 | **Реальная локализация** ✅ | `ScanMatchLocalizer` (одометрия + сопоставление скана с сеткой занятости, локальный поиск позы) вместо truth | Поза оценивается без подсказки симулятора, теряется корректно |
| 6 | **Следование за человеком** ✅ | `TargetDetector` + `SimPerson`/`SimPersonDetector` (дальность, FOV, прямая видимость), `PersonFollower` (удержание дистанции, безопасный стоп), режим `FOLLOWING` | Робот едет за движущейся целью, безопасно останавливается при потере |
| 7 | **Закрытые зоны (keep-out)** ✅ | `InMemoryKeepoutRegistry` (растеризация KEEPOUT в занятость + слой стоимости SLOW/PREFERRED), слой стоимости в A*, интеграция в `SimGoalNavigator` | Отмеченная зона не пересекается маршрутом; правка зон на лету |
| 8 | **Несколько роботов / проезды** ✅ | `InMemoryTrafficCoordinator` (взаимное исключение сегментов, атомарный резерв маршрута против тупиков), несколько `SimRobot` в одном мире | Два робота не встречаются в узком ряду, нет тупиков |
| 9 | **Зарядка** ✅ | док-точка и подзарядка в `SimEngine`, `SimChargeController` (порог заряда → доезд до дока → режим `CHARGING` → заряд до полного) | Робот сам едет на зарядку при низком заряде |
| 10 | **Автономное исследование (exploration)** ✅ | `nearest_frontier` (поиск открытой границы «свободно↔неизвестно» по evidence-сетке) + `SimExplorer` (едет к ближайшему фронтиру, планируя только по построенной карте, чёрный список недостижимых границ, завершение по отсутствию фронтиров); интегрировано в сцену (клавиша `M`) | Робот без априорных данных сам объезжает теплицу и строит полную карту, без телеопа |
| 11 | **Непрерывная актуализация карты** ✅ | `ConfidenceGatedMapper` (ingest на ходу только при достаточном `confidence`) + хук `live_mapper` в `SimRobot` (режимы `NAVIGATING`/`FOLLOWING`); `DynamicObstacleLayer` (краткоживущий слой динамики с TTL); `merge_occupancy`, `InMemoryMapStore`/`FileMapStore` (сохранение/слияние, переживает перезапуск) | Появившееся/исчезнувшее препятствие отражается в карте при последующих проездах; ложная засветка не «размазывает» стены; карта переживает перезапуск |
| 12 | **Слияние IMU в локализацию** | подключение `ImuSource` (BNO085) в цикл; фьюжн гироскопа/одометрии для прогноза курса, с которого стартует scan-matching; устойчивость к проскальзыванию колёс | На железе/в сим-модели со скольжением оценка курса не плывёт; локализация надёжнее на поворотах |
| 13 | **Децентрализованная уступка / разъезд** | режим `RobotMode.YIELDING`; обмен намерениями напрямую между роботами (peer-to-peer, без сервера); детерминированная функция приоритета (гружён > порожний → дешевле отъехать → выше заряд → тай-брейк по `robot_id`) — оба считают её одинаково и приходят к одному решению; уступающий едет к ближайшей точке разъезда, пропускает, возвращается; anti-starvation (приоритет растёт после уступок); fallback без связи — рандомизированный backoff поверх реактивного объезда | Два робота сами разъезжаются в тупиковом ряду без какой-либо внешней инфраструктуры; нет лобовых, тупиков и зацикливания; при полной потере связи разъезд всё равно происходит |
| 14 | **Мост к ROS 2** | `adapters/ros2`: `/scan`, `/cmd_vel`, Nav2/slam_toolbox за теми же интерфейсами | То же ядро работает поверх ROS 2 на стенде |
| 15 | **Backend флота** | приём телеметрии, отправка задач/команд, реестр роботов, мониторинг и карты. **Не на критическом пути безопасности**: разъезд и объезд (Инкр. 13) работают и без связи с сервером | Оператор видит флот, ставит задачи; роботы продолжают безопасно работать при потере связи с backend |

## Принцип переноса в железо

Планирование и проверка коллизий всегда используют **единую модель занятости**
(габарит робота + карта + зоны). В симуляции — диск против сегментных стен; в Nav2 —
polygon footprint + costmap. Сохраняя одну геометрию, поведение из симуляции переносится
на железо предсказуемо.
