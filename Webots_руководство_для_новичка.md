# Симуляция колёсного робота в Webots — руководство для новичка (macOS)

Webots — бесплатная среда для виртуальной сборки робота: добавляешь корпус, колёса, датчики, лидар, камеру, строишь комнату и тестируешь поведение без физического прототипа. Идеально для старта на Mac.

---

## 1. Установка (macOS)

Актуальная версия — **R2025a**. Два способа:

**Через Homebrew (рекомендую):**

```bash
brew install --cask webots
```

**Или вручную:** скачать `.dmg` со страницы релизов — https://github.com/cyberbotics/webots/releases — перетащить Webots в «Программы».

> При первом запуске macOS может предупредить о неизвестном разработчике: Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно». Работает и на Apple Silicon (M1/M2/M3), и на Intel.

---

## 2. Знакомство с интерфейсом

После запуска: **File → Open Sample World** — там десятки готовых примеров. Открой, например, `robots/.../e-puck` или `samples/devices/lidar.wbt`, нажми ▶️ (Play) и посмотри, как робот ездит.

Главные панели:
- **Слева — Scene Tree** (дерево сцены): здесь весь мир и все компоненты робота в виде узлов (nodes).
- **Центр — 3D-вид**: сама сцена.
- **Снизу — консоль**: вывод программы-контроллера.
- **Сверху — кнопки** Play / Pause / Step / скорость симуляции.

---

## 3. Создаём свой мир и комнату

1. **File → New → New Project Directory** — задай имя проекта (например, `MyRobot`). Webots создаст папку с миром `.wbt` и папкой контроллеров.
2. В дереве сцены справа клик правой кнопкой → **Add** → добавь:
   - `RectangleArena` — готовая комната с полом и стенами (самый простой способ построить помещение). Размер задаётся в полях `floorSize`.
   - Объекты-препятствия: из меню **Add → PROTO nodes → objects** (коробки, мебель, банки и т.д.).

Так за пару минут собирается комната, в которой робот будет ездить.

---

## 4. Собираем колёсного робота

Самый простой путь для новичка — взять готового робота и доработать его:

**Вариант А (проще):** Добавь готового робота `e-puck` или `Pioneer 3-DX` (Add → PROTO nodes → robots). У них уже есть колёса, моторы и базовые датчики — сразу можно ездить.

**Вариант Б (собрать самому):** добавь пустой `Robot` node, внутрь него:
- `Solid` с `Shape` — корпус (например, коробка `Box`).
- Два `HingeJoint` с `RotationalMotor` — это колёса с моторами. Каждому мотору задай имя (`left wheel motor`, `right wheel motor`) — по нему контроллер обращается к колесу.
- Колёса — цилиндры (`Cylinder`).

Получается дифференциальный привод (как у пылесоса-робота): два независимых колеса + опорный ролик.

---

## 5. Добавляем датчики, лидар и камеру

Все сенсоры добавляются как дочерние узлы внутрь робота (правый клик на Robot → Add):

- **Лидар** — узел `Lidar`. Параметры: `horizontalResolution` (число лучей), `fieldOfView` (угол обзора), `maxRange` (дальность). Даёт облако расстояний вокруг робота.
- **Камера** — узел `Camera`. Параметры `width`/`height` — разрешение картинки.
- **Датчики расстояния** — `DistanceSensor` (ИК/ультразвук), ставятся по периметру для объезда препятствий.
- **IMU / гироскоп** — `InertialUnit`, `Gyro`, `Accelerometer`.
- **Энкодеры колёс** — уже встроены в `PositionSensor` на моторах (одометрия).

Важно: каждому устройству давай уникальное **имя** (поле `name`) — именно через него код «видит» датчик.

## 6. Пишем простой контроллер (Python)

Webots поддерживает Python «из коробки». В дереве выбери Robot → поле `controller` → создай новый контроллер на Python. Пример — робот едет вперёд и тормозит перед стеной по лидару/датчику:

```python
from controller import Robot

robot = Robot()
timestep = int(robot.getBasicTimeStep())

# Моторы (имена должны совпадать с заданными в дереве сцены)
left = robot.getDevice("left wheel motor")
right = robot.getDevice("right wheel motor")
left.setPosition(float('inf'))   # режим скорости
right.setPosition(float('inf'))
left.setVelocity(0.0)
right.setVelocity(0.0)

# Датчик расстояния спереди
ds = robot.getDevice("front distance sensor")
ds.enable(timestep)

# Камера и лидар (включаем, если добавлены)
# cam = robot.getDevice("camera"); cam.enable(timestep)
# lidar = robot.getDevice("lidar"); lidar.enable(timestep)

MAX_SPEED = 6.0

while robot.step(timestep) != -1:
    distance = ds.getValue()
    if distance > 200:          # препятствие близко
        # поворот на месте
        left.setVelocity(MAX_SPEED)
        right.setVelocity(-MAX_SPEED)
    else:
        # едем вперёд
        left.setVelocity(MAX_SPEED)
        right.setVelocity(MAX_SPEED)
```

Нажми ▶️ — робот поедет по комнате и начнёт объезжать стены.

## 7. Тестируем компоненты

- **Скорость симуляции**: кнопками сверху можно замедлить/ускорить время.
- **Просмотр данных датчиков**: правый клик на устройстве в дереве → есть оверлеи (картинка с камеры, облако точек лидара показываются прямо в 3D-виде).
- **Robot window**: двойной клик по роботу открывает окно с графиками сенсоров — удобно проверять, что компонент работает как надо.
- Подменяй компоненты (другой лидар, другая камера, другое расположение датчиков) и сразу смотри результат — это и есть тестирование «железа» до покупки.

## 8. Куда расти дальше

- **ROS 2**: Webots официально интегрируется с ROS 2 (`webots_ros2`) — когда захочешь приблизить симуляцию к реальному роботу.
- **Реалистичная физика/рендер**: если позже появится ПК с мощной NVIDIA GPU — стоит посмотреть NVIDIA Isaac Sim; на Linux — Gazebo + ROS 2.
